## Classement

- Une méthode ou une technologie réutilisable va dans `02-Tech/<domaine>/`.
- Un projet personnel conserve une fiche de suivi dans `01-Projets/` ; ses livrables de code restent dans le dépôt du projet.
- Les images, captures et documents source restent liés à la note qui les utilise ou rangés dans `attachments/`.
