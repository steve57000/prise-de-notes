# 📊 Prise en main d'Excel -- Résumé clair et simple

## 🚀 1. Démarrer Excel

Tu peux ouvrir Excel de deux façons :

-   **Depuis le bureau** : double-clique sur l'icône Excel.
-   **Depuis le menu Démarrer** :
    -   Clique sur le bouton **Démarrer**
    -   Cherche à la lettre **E**
    -   Ou tape *Excel* dans la barre de recherche

------------------------------------------------------------------------

## 📂 2. Créer un nouveau classeur

Quand Excel s'ouvre :

-   Clique sur **Nouveau classeur**
-   Tu peux aussi utiliser un **modèle**, mais pour commencer choisis un
    classeur vide.

Un fichier Excel s'appelle un **classeur**.

------------------------------------------------------------------------

## 💾 3. Enregistrer un classeur

1.  Clique sur l'icône **Enregistrer** (en haut à gauche)
2.  Renomme le fichier (ex: *Mon premier classeur*)
3.  Choisis l'emplacement :
    -   **OneDrive** → stockage en ligne (cloud)
    -   **Documents** → stockage sur ton ordinateur
4.  Clique sur **Enregistrer**

### Raccourci utile :

`CTRL + S` → enregistrer rapidement

👉 Après le premier enregistrement, Excel met simplement le fichier à
jour.

------------------------------------------------------------------------

## ❌ 4. Fermer un classeur

Deux méthodes :

-   **Fichier → Fermer**
-   Cliquer sur la croix en haut à droite (ferme aussi Excel)

------------------------------------------------------------------------

# 🧭 Se repérer dans Excel

## 📑 1. La feuille de calcul

Excel est une immense grille composée de :

-   **Colonnes** → Lettres (A, B, C...)
-   **Lignes** → Chiffres (1, 2, 3...)

Une feuille contient : - 16 384 colonnes (A → XFD) - 1 048 576 lignes

------------------------------------------------------------------------

## 🔲 2. Les cellules

Une **cellule** est l'intersection d'une colonne et d'une ligne.

Exemple : - Colonne A + Ligne 1 = **A1**

👉 La référence d'une cellule correspond à sa position.

Quand une cellule est sélectionnée, elle est appelée **cellule active**.

------------------------------------------------------------------------

# 🖱 Sélectionner dans Excel

## ✅ Sélectionner une cellule

Clique simplement dessus (ex : C3).

------------------------------------------------------------------------

## 🔷 Sélectionner plusieurs cellules adjacentes (plage)

Méthode 1 : - Clique sur la première cellule - Glisse la souris jusqu'à
la dernière

Méthode 2 : - Clique sur la première cellule - Maintiens **Maj** -
Clique sur la dernière

Exemple :\
`B4:C9` signifie → de B4 **jusqu'à** C9

------------------------------------------------------------------------

## 🔹 Sélection multiple (cellules séparées)

-   Clique sur une cellule
-   Maintiens **Ctrl**
-   Clique sur les autres cellules

------------------------------------------------------------------------

## 📊 Sélectionner une colonne

-   Clique sur la **lettre** en haut (ex : D)
-   Glisse pour sélectionner plusieurs colonnes

------------------------------------------------------------------------

## 📈 Sélectionner une ligne

-   Clique sur le **numéro** de la ligne (ex : 3)
-   Glisse pour sélectionner plusieurs lignes

------------------------------------------------------------------------

# 🎯 À retenir

-   La cellule est l'élément de base d'Excel.
-   Une cellule = 1 colonne + 1 ligne.
-   Une cellule a une **référence** (ex : A1).
-   Une sélection continue = **plage de données**.
-   `CTRL + S` est ton meilleur ami 😄
