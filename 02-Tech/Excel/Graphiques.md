# 📊 Excel – Créer et personnaliser des graphiques

## ✅ Objectif
Apprendre à :
- créer un graphique à partir d’un tableau
- choisir le bon type de graphique
- personnaliser (titre, axes, légende…)
- déplacer le graphique

---

# 1) 📈 Pourquoi utiliser un graphique ?

Un graphique permet de rendre les données :
- plus **visuelles**
- plus **compréhensibles**
- plus **parlantes**

📌 Important : un graphique se **met à jour automatiquement** si les données changent.

---

# 2) 🧩 Étapes pour créer un graphique

## 1️⃣ Sélectionner les données

Toujours commencer par :
- sélectionner les **données**
- inclure les **titres de colonnes**

Exemple :
- Mois → B3:B9
- Chiffre d'affaires → D3:D9

Les titres servent automatiquement pour :
- le titre du graphique
- la légende

---

## 2️⃣ Choisir le type de graphique

Onglet **Insertion** → groupe **Graphiques**

Principaux types :

### 📊 Histogramme (barres)
- Compare des valeurs
- Idéal pour comparer plusieurs mois ou catégories

### 📈 Courbe
- Montre une **évolution dans le temps**
- Idéal pour suivre un CA mensuel

### 🟢 Nuage de points
- Montre la relation entre deux variables

### 🥧 Secteur (camembert)
- Montre des **proportions / répartitions**

---

## Exemple : évolution du CA
- Axe horizontal (abscisses) → Mois
- Axe vertical (ordonnées) → Chiffre d’affaires

Insertion :
1. Sélectionner les données
2. Insertion → Histogramme 2D → Histogramme groupé
3. Excel génère automatiquement le graphique

---

# 3) 🎨 Mettre en forme le graphique

## 🏷 Modifier le titre
- Cliquer sur le titre
- Modifier le texte
- Valider avec Entrée

Si absent :
- Onglet **Création de graphique**
- **Ajouter un élément graphique**
- Titre du graphique

---

## 🧭 Ajouter titres d’axes
- Création de graphique
- Ajouter un élément graphique
- **Titres des axes**

---

## 📌 Ajouter une légende
Permet d’identifier les séries de données.
Peut être placée :
- à droite
- en bas
- directement sur le graphique

---

## 🔢 Afficher les valeurs
Possible d’afficher :
- les valeurs exactes
- les pourcentages (ex : graphique en secteur)

---

# 4) 📍 Déplacer le graphique

Pour placer le graphique sur une autre feuille :

1. Sélectionner le graphique
2. Onglet **Création de graphique**
3. **Déplacer le graphique**
4. Choisir :
   - nouvelle feuille
   - feuille existante

---

# 🎯 Choisir le bon graphique

| Type | Utilisation |
|------|------------|
| Histogramme | Comparer des valeurs |
| Courbe | Montrer une évolution |
| Secteur | Montrer une répartition |
| Nuage de points | Relation entre 2 variables |

---

# ✅ À retenir

- Toujours sélectionner les données AVANT d’insérer le graphique
- Inclure les titres de colonnes
- Les graphiques se mettent à jour automatiquement
- Bien choisir le type selon l’objectif
- Personnaliser titre, axes et légende pour plus de clarté

---

🔥 Les graphiques rendent ton analyse beaucoup plus professionnelle et compréhensible !
